# Offline Edge AI Digital Sign

This example demonstrates a simple 'offline model' running on an edge device. It simulates a digital sign that displays different messages based on the local time, without requiring any internet connection or cloud processing. This illustrates how devices can make autonomous decisions using on-device AI, a core concept of the article.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
